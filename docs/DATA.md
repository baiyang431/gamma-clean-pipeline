# 数据说明

## 来源与许可

`examples/dirty.csv` 是本项目构造的合成数据，没有采集真实人员或业务记录，也没有使用第三方数据集。源码、说明和合成样例按根目录 MIT License 提供。

`examples/expected/clean.csv` 是按样例规则单独编写的预期结果，用于比较实际清洗输出。其他边界输入由测试临时生成；GB18030 输入由同一份 UTF-8 样例转码得到。

## 用途划分

- `dirty.csv` 用于演示和回归测试。
- `expected/clean.csv` 用于检查结果。
- 测试脚本中的临时数据用于编码、非法值、配置和文件异常等检查。

本项目不训练模型，没有机器学习训练集和测试集。样例业务规则由本项目定义：编号和姓名必填、年龄在 0 到 120 之间且允许缺失、城市缺失填“未知”、金额非负、日期为有效 ISO 日期、状态为 `active` 或 `inactive`。具体字段配置以 `examples/schema.json` 为准。

## 版本

数据版本为 `synthetic-v1`，规则格式版本为 `1`。本次精简未更改输入和预期 CSV。代码版本使用所提交的 Git commit 标识；尚未提交的本地修改不属于原 commit。

`.gitattributes` 将文本换行固定为 LF。运行和测试结果统一见 `REPORT.md`。
