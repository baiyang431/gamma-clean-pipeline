# 提交说明

提交前按 README 执行测试和样例运行，检查 `docs/REPORT.md`、`docs/unit-tests.txt` 和 `docs/verification.json` 是否与当前代码一致。

仓库应包含源码、测试、样例、README、数据及环境说明、报告和真实运行记录。`results/`、虚拟环境和 Python 缓存由 `.gitignore` 排除。

提交平台需要填写仓库地址及本次提交的 commit，可在项目根目录查看：

```console
git remote -v
git rev-parse HEAD
git status --short
```

有未提交修改时，远端仓库尚不包含这些修改。按课程要求一并保留实际使用的工具、协作及资料引用说明；当前数据为合成数据，来源与许可见 `DATA.md`。
